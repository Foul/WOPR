# Publication publique de WOPR

WOPR est publié sous licence **GNU GPLv3**. Le code public peut être partagé, étudié et modifié dans le respect de cette licence.

## À publier

- le code du dossier `public/` ;
- les templates et ressources génériques ;
- les lanceurs/binaries destinés à la distribution ;
- `requirements.txt` ;
- la documentation publique ;
- `LICENSE` ;
- un `.gitignore` adapté.

## À ne jamais publier

Le dossier `private/` et son contenu ne doivent jamais être inclus dans une publication publique. Cela concerne notamment :

- bases SQLite et sauvegardes ;
- clés, jetons et secrets ;
- paramètres SMTP / Abby / OAuth ;
- signatures ;
- factures, devis et suivis réels ;
- exports clients ;
- toute capture contenant des données personnelles ou commerciales réelles.

## Plateformes officielles

- Linux : supporté.
- Windows : supporté.
- macOS : non supporté.

## Dons

Le développement peut être soutenu volontairement sur https://paypal.me/foul. Un don n’est jamais nécessaire pour utiliser WOPR et ne débloque aucune fonctionnalité.
