# WOPR 2.4.0

## Release stable — 16 septembre 2026

Cette release rend l’utilisation quotidienne de l’atelier plus sûre devant un client et fiabilise la préparation des paiements.

### Mode Client
- Le tableau de bord peut masquer les noms, problèmes, factures et montants sensibles.
- Le bouton Mode Client / Mode Admin reste disponible dans le même style que les actions 8-BIT.
- Nouvelle réparation reste accessible en Mode Client.
- Le logo Foul-Fix est affiché dans le bandeau et centré avec le thème actif.

### Factures et SumUp
- L’entreprise du client apparaît dans la liste des factures lorsqu’elle est renseignée.
- La préparation SumUp reprend le montant exact de la facture.
- La remarque SumUp est générée au format `Nom Prénom — facture XXXXX` et peut être copiée directement.

### Fiabilité et interface
- Contrôles CA et navigation consolidés.
- Corrections de débordement et de barres de défilement du bandeau.
- Documentation et version publique alignées sur 2.4.0.

Cette version est stable. Les données privées, bases SQLite et paramètres locaux restent hors du code public.
