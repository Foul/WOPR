## Plateformes supportées

| Système | Statut |
| --- | --- |
| Linux | **Supporté** |
| Windows | **Supporté** |
| macOS | **Non supporté** |

### macOS

macOS n’est pas une plateforme supportée par WOPR : aucun binaire macOS officiel n’est fourni, aucun test de compatibilité n’est effectué et aucun fonctionnement n’est garanti.

Une adaptation ou une compilation communautaire reste naturellement possible dans le respect de la GPLv3, mais elle ne constitue pas une version officiellement supportée par Foul-Fix.
