# Maintenance de la documentation WOPR

Version de référence actuelle : **2.3.192**.

À chaque évolution visible de WOPR :

1. mettre à jour `manuel.md` ;
2. mettre à jour `index.html` ;
3. régénérer le PDF ;
4. ajouter l’évolution dans `CHANGELOG-DOC.md` ;
5. vérifier l’absence de données privées.

La documentation ne doit pas être intégrée dans l’interface WOPR : elle reste un livrable séparé, publiable au choix sur GitHub et/ou sur le site de Foul-Fix.
