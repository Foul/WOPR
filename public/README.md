# WOPR — cœur public

Ce dossier contient le code public de **WOPR — Workflow d’Organisation et de Pilotage des Réparations**.

Les données d’exploitation, bases SQLite, documents clients, clés, jetons, paramètres et personnalisations d’entreprise sont conservés dans `../private/` et ne doivent pas être publiés.

La documentation utilisateur et la documentation de publication se trouvent à la racine du dépôt et dans `../docs/`.

## Identité de l’entreprise

WOPR est générique : le nom de l’entreprise, le responsable, l’adresse, le site, l’e-mail, les informations légales, le logo de facture et les paramètres de messagerie proviennent de la configuration locale privée. Aucune identité d’entreprise réelle ne doit être codée en dur dans ce dossier public.

## Développement

Développé par **Foul-Fix**, avec l’aide de **ChatGPT (OpenAI)** pour l’assistance au développement, à la documentation et aux tests.
